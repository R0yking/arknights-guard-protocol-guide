# 卫戍协议 · 盟约指南

《明日方舟》卫戍协议同人攻略，收录 10 个核心盟约、12 个附加盟约、干员头像及 22 张站位示意图。

- 从首页选择盟约查看站位。点开详情可查主要干员、叠层方法和配置建议。
- 点击头像可放大。站位图可另存为 SVG，图片来源不可用时仍会显示干员名称和站位。
- 站位图绘制前后排、相邻和朝向关系。实战格子按地图调整。

## 使用

用浏览器打开 index.html 即可。项目无需安装依赖。部署到 GitHub Pages 时，可选择 main 分支的仓库根目录作为发布来源。
